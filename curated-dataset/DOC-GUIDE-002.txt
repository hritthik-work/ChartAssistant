1. PURPOSE
This document provides fictional examples for preserving condition status over
time in a retrieval workflow. It is not official clinical, coding, or payer
guidance.

2. STATUS CATEGORIES
An acute condition applies to the specific episode described by the source. A
chronic condition may continue across visits when documentation supports it. A
historical condition describes a past event. A residual deficit or sequela may
persist after the original event and must not be represented as a new acute event.

3. CHRONOLOGY
The encounter date, source type, and narrative context should be retained during
ingestion. A discharge summary may describe an acute hospitalization, while a
later follow-up may state that symptoms have improved. The later source should
not be read as evidence that the original acute episode continues unless it says
so explicitly.

4. EXACERBATION AND STABILITY
An established chronic condition and an acute exacerbation are different clinical
statuses. For example, documentation of stable COPD does not support an acute
COPD exacerbation. A workflow must preserve explicit statements of stability,
improvement, resolution, or absence of an acute event.

5. SOURCE-BOUND SUMMARY
When multiple records are used, a response should name the relevant time frame.
If status cannot be determined from retrieved text, the response should flag the
uncertainty for human review rather than select a more specific status.
