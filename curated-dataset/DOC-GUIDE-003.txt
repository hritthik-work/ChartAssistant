1. PURPOSE
This synthetic reference explains how a source-grounded workflow should handle
diagnostic specificity and relationships between conditions.

2. USE ONLY SUPPORTED SPECIFICITY
The workflow should state only the level of detail present in the source. If a
chart states "chronic kidney disease stage 3b," that documented stage can be
reported. If a chart provides only a laboratory finding, it must not invent a
chronic kidney disease stage or diagnosis.

3. DO NOT INVENT LINKAGE
Two conditions appearing in the same chart are not automatically causally linked.
Diabetes and a reduced eGFR result do not establish diabetic kidney disease.
Anemia in a patient with chronic kidney disease does not establish that CKD caused
the anemia unless a qualified source explicitly states the relationship.

4. CODE LOOKUP BOUNDARY
A limited code-reference table may provide a descriptor for a requested code.
It does not determine whether the patient has the condition, whether additional
specificity exists, or whether a code is appropriate for a real-world claim. The
chart evidence must be considered first, and qualified review remains necessary.

5. INSUFFICIENT DOCUMENTATION
If a requested degree of severity, laterality, complication, or causal linkage is
not documented, the safe outcome is to report that it is not established by the
retrieved material. Do not select a more specific alternative merely because it
is clinically plausible.
