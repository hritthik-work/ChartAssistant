# Synthetic Healthcare Dataset

This folder contains curated, synthetically created healthcare datasets.
All names, dates, places, and patient details are fictional.

## What is included

| File type | Count | Prefix |
|---|---:|---|
| Clinical notes | 15 | `DOC-CLIN-` |
| Documentation guides | 5 | `DOC-GUIDE-` |
| Payer-policy examples | 5 | `DOC-POLICY-` |
| Text files in total | 25 | `DOC-*.txt` |

All files are directly inside this folder.

## File details

Each file starts with basic details such as its ID, title, type, date, and source
role. Clinical notes also include a fictional patient and encounter ID.

The files use clear labels for confirmed conditions, symptoms, test results,
family history, past conditions, and conditions that are still being checked.

## Notes

- The data is fictional and must not be used for real patient care, coding,
  billing, legal decisions, or payer decisions.
- Each source file includes a synthetic-data notice.
